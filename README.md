# BioCodeTalks

Code, data, analyses, and reproducible examples accompanying videos from **BioCodeTalks**.

BioCodeTalks explores biology through computation, code, and scientific curiosity.

**Code. Converse. Discover.**

## Projects

### The Banana Apocalypse? Let's Investigate with Genomics and Code

Companion material for a BioCodeTalks investigation of banana evolution, comparative genomics, Panama disease, and the genetics of disease resistance.

See `banana_apocalypse/` for the analysis code, data snapshots, generated results, figures, and Manim source used for the video.

## Reproducibility

Each project documents its own data sources, computational assumptions, and reproduction instructions.

Third-party datasets and resources remain subject to their original licenses and terms.

### Same Data, Different Boxplot? | Method Matters

Companion material for a BioCodeTalks episode on boxplots, quartile definitions, quantile algorithms, approximate quantile sketches, and how methodological choices can change the same data visualization.

See `boxplot_method_matters/` for reproducible code, frozen results, and Manim source used in the episode.
